# Fern — Episode 1 Key Frames for Midjourney

Ready-to-paste Midjourney prompts for the key frames of **Scrolltown: The Great Form Mix-Up** (Episode 1), built from Will's canonical Fern render (the saved high-quality portrait — scroll-puff buns, freckles, coral overalls, brass key-badge — is the design of record).

## How to use these

- Every prompt below is **character block + the moment + style block**, complete and paste-ready. The character block and style block are identical in all eight prompts — do not edit them between frames; that sameness is what holds Fern's likeness across the set.
- In each prompt, replace **FERN_URL** with the image URL of the saved Fern render (upload it to Midjourney/Discord first) so `--cref` locks her face, hair, and outfit. `--cw 90` keeps the reference strong on the outfit too; drop to `--cw 60–70` if a pose comes out stiff, raise to `--cw 100` if her clothes drift.
- For extra style lock, the same render can go in as `--sref FERN_URL`. `--cref` is the important one; `--sref` is optional seasoning.
- All frames are `--ar 16:9` (episode frames). For a poster/portrait of any frame, re-run it with `--ar 4:5`.
