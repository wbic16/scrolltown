# Hypothesis H8 — more prompt craft would have closed the gap

Claim (to be tested, not assumed): Emise's generated key frames
failed for want of prompt craft, and better prompting — not a
different division of labor — is what the artists' results point to.

Evidence walked:
- Burn 2 ran the full countermeasure stack — shorter clips, wider
  framing, static camera as the prompt's first sentence, explicit
  style lock, anchors re-asserted by name, start and end poses both
  named — and its own QC refuted the stack's promises one by one:
  the push-in happened anyway, identity failed under body motion,
  a named anticipation was promoted to the main action
  (24.7.9/8.7.11/7.6.8).
- Burn 3 removed anticipation language entirely and restricted motion
  to one arm; the gesture landed and the hair still re-drew
  (25.8.8/9.7.12/7.6.9).
- Burn 4 tried explicit permanence language ("only ever ONE token…
  never becomes a ball, never splits"); the failure changed mode
  instead of curing — the token morphed in place. Two supplied keys
  were blended into a re-staged scene (25.7.10/8.6.10/7.6.9).
- Four burns of iterated, evidence-driven prompt refinement moved
  the failures around; none removed the class. The programme's own
  conclusion, recorded in QC-v4, is to change the instrument, not
  the prompt: exact physics goes to the drawn route.

Verdict: REFUTED. Prompt craft was iterated with discipline across
four burns; the gap it could not close is the gap the packet system
routes around.
