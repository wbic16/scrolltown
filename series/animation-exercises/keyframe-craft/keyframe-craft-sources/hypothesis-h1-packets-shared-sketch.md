# Hypothesis H1 — addressed packets with a shared arc-sketch reference

Claim: the artists handle key frames well because their work arrives as
addressed packets — one artist, one operation, one return coordinate —
that all cite a shared arc-sketch reference, so every worker and every
QC pass is looking at the same guiding light.

Evidence walked:
- The Iteration 2 packets (27.6.9/8.6.11/7.6.9) record both sweat
  batches in exactly this form: artist by name and machine, frame
  range, one operation, done-definition, return coordinate, and the
  Iteration 2 agenda named as the arc-sketch reference for both.
- The Gate 1 packets (30.7.9/8.7.13/9.6.9) cite the arc sketch's
  phext coordinate (22.6.8/7.6.10/7.5.8) in every packet; all four
  delegated packets (acquisition, survey, extraction, assembly)
  returned artifacts that were verified, never taken on say-so.

Qualification the evidence forces: Emise's generated clips also
carried references — canonical stills passed to the generator — and
failed anyway (23.7.9/8.7.10/6.6.9, 24.7.9/8.7.11/7.6.8). A shared
reference alone does not produce the artist results. What the packet
adds beyond a reference is the binding: one named owner, one
operation, one address the work must land at.

Verdict: SUPPORTED as a contributing mechanism — the scaffolding the
other mechanisms stand on — not sufficient by itself.
