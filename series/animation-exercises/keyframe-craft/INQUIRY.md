## The synthesis (full text at 27.7.9/9.6.11/6.6.9 in the phext)

A correction first: the artists, on this record, mostly did not draw
key frames generatively at all — they handled the frame work around
the keys (measurement, conform, enumeration, variant stills,
extraction, assembly), and the one full drawing pass (Gate 1's
pages) was Emise's deterministic renderer, not delegated
(30.7.9/8.7.13/9.6.9). Work dispatched to the artists has never yet
failed a verdict; Emise's generated key-frame work failed in every
burn. Five mechanisms survive testing, operating as one system:

1. **The route, not the worker** (H2, 25.7.9/9.7.12/8.6.9 —
   SUPPORTED, primary). Artist operations are deterministic or
   reference-locked: hash-verified acquisition, threshold detection,
   per-frame phase correlation, a seeded renderer. Their defects are
   systematic (the wash defect, identical on all 60 pages,
   26.8.9/10.7.12/7.7.8) — found once, fixed in one place. Generator
   defects are fresh inventions per attempt (23.7.9/8.7.10/6.6.9;
   24.7.9/8.7.11/7.6.8; 25.8.8/9.7.12/7.6.9; 25.7.10/8.6.10/7.6.9).
2. **One concern per packet** (H5, 26.6.12/8.6.10/6.5.10 —
   SUPPORTED). 60 frames measured, 180 enumerated, nothing traded
   against anything else (27.6.9/8.6.11/7.6.9); generated clips fail
   exactly at the joints between simultaneously-held concerns.
3. **Addressing lets enumeration replace sampling** (H3,
   26.7.11/9.7.14/7.6.9 — SUPPORTED). Five anchors at 180/180,
   enumerated (18.13.15/9.12.15/13.14.16); "reframing" resolved to a
   measured ≈4 % zoom (39.23.21/18.25.19/15.15.18); per-page scoring
   caught a never-drawn title card sampling had missed
   (26.8.9/10.7.12/7.7.8).
4. **Done-definitions stated first, in executable shape** (H4,
   31.6.9/8.7.12/8.5.9 — SUPPORTED, refined). An exact byte size and
   hash; a table with zero unexamined frames. Written definitions
   alone did not save the generated clips; executable ones are the
   difference.
5. **The packet binding** (H1, 28.7.12/9.7.13/8.6.9 — SUPPORTED,
   contributing). One named artist, one operation, one return
   coordinate, one shared sketch cited by all — the scaffolding
   that routes work into mechanisms 1–4.

Did not survive: **store-and-forward patience** (H6,
25.8.11/10.7.13/8.6.9) — UNPROVEN, consistent with the record but
never isolated by it. **The artists are better generators** (H7,
27.6.8/8.6.10/6.5.9) — REFUTED: the wins are CPU/frame operations;
the one generative return passed at draft grade under a likeness
check (22.6.9/7.6.10/7.6.8). **More prompt craft would close the
gap** (H8, 26.7.9/8.6.11/7.6.9) — REFUTED across four burns of
evidence-driven prompt refinement (24.7.9/8.7.11/7.6.8;
25.8.8/9.7.12/7.6.9; 25.7.10/8.6.10/7.6.9).

In one breath: the artists handle key frames so well because the
dispatch system never hands them the part that fails. Sustaining
invented content across time is the one operation this programme has
never made work; the packet discipline decomposes key-frame work
until nothing undecomposable remains — each piece addressed,
single-concern, deterministic or reference-locked, defined by a
check that can be run, and returned to the very coordinate where QC
enumerates it.
